1 បង្កើត Bot និង Channel លើ Telegram

១.១ បង្កើត Telegram Bot

  1. បើក Telegram ស្វែងរក @BotFather
  2. ផ្ញើសារ /newbot
  3. ដាក់ឈ្មោះ Bot របស់លោកអ្នក (ឧទាហរណ៍: ANC Player Pro)
  4. ដាក់ Username Bot ដែលបញ្ចប់ដោយពាក្យ bot (ឧទាហរណ៍: AncPlayerBot)
  5. BotFather នឹងផ្ដល់ជូន HTTP API Token (ហៅកាត់ថា BOT_TOKEN)៖
    8445405147:AAH51CWfNzBADynBFcGV1yHb5gcraKlkjhg
    (សូមកត់ទុកលេខកូដនេះ)

១.២ យក API_ID និង API_HASH (Telegram Keys)

  1. ចូលទៅកាន់វេបសាយផ្លូវការ Telegram: my.telegram.org
  2. វាយបញ្ចូលលេខទូរស័ព្ទ Telegram រួចវាយលេខកូដសម្ងាត់ដែល Telegram ផ្ញើចូលក្នុង App
  3. ចុចលើពាក្យ API development tools
  4. បំពេញឈ្មោះ App អ្វីក៏បាន (ឧ. VideoStreamer) រួចចុច Submit
  5. លោកអ្នកនឹងទទួលបាន៖
    • App api_id: ជាលេខ (ឧ. 38606693)
    • App api_hash: ជាអក្សរនិងលេខវែង (ឧ. 4784d8963ea114bcd26dd59d84f997ad)
    (សូមកត់ទុកព័ត៌មានទាំងពីរនេះ)

១.៣ បង្កើត Channel ផ្ទុកវីដេអូ (Bin Channel)

  1. ចុចបង្កើត New Channel មួយលើ Telegram
  2. ជ្រើសរើសប្រភេទជា « Private Channel » (ដាច់ខាតកុំដាក់ Public ដើម្បីការពារការ Report រឿង Copyright)
  3. Add Bot ដែលទើបបង្កើតចូលក្នុង Channel នោះ
  4. ចូលទៅ Manage Channel -> Administrators -> លើក Bot ឱ្យទៅជា Admin ដោយបើកសិទ្ធិទាំងអស់
  5. យក Channel ID៖
    • Forward សារមួយពី Channel នោះទៅកាន់ bot @userinfobot
    • បងនឹងឃើញលេខសម្គាល់ Channel ដែលចាប់ផ្ដើមដោយ -100 (ឧ. -1003909046470)

2 ទិញ និងបង្កើត VPS (Singapore)

  1. ចូលទៅកាន់ DigitalOcean.com (ឬ Linode / Hetzner)
  2. ចុច Create -> Droplets
  3. កំណត់ជ្រើសរើសដូចខាងក្រោម៖
    • Region (ទីតាំង): Singapore 🇸🇬 (ល្បឿនមកកម្ពុជាលឿនបំផុត ~40ms)
    • OS (ប្រព័ន្ធប្រតិបត្តិការ): Ubuntu 24.04 LTS (ឬ 22.04)
    • Size: Basic Plan - 1GB RAM / 1 vCPU ($6/ខែ) ឬ 512MB RAM ($4/ខែ)
    • Authentication: Password (ដាក់ Password ខ្លាំងមួយសម្រាប់ Login)
  4. ចុច Create Droplet រួចរង់ចាំប្រហែល ១ នាទី លោកអ្នកនឹងទទួលបាន IPv4 Address (ឧទាហរណ៍: 157.245.201.238)

3 កំណត់ DNS លើ Cloudflare (DNS Only)

ចំណុចសំខាន់ដាច់ខាត៖ ត្រូវបិទពពកពណ៌ទឹកក្រូចឱ្យទៅជា ពពកពណ៌ប្រផេះ (DNS only)។ ប្រសិនបើបើក Proxied នោះ Cloudflare នឹងកំហិតល្បឿនវីដេអូឱ្យនៅសល់ត្រឹម ~700 KB/s។ ពេលបិទទៅ DNS only ល្បឿននឹងស្ទុះដល់ 60+ Mbps (8.3 MB/s) ភ្លាមៗ!
  1. ចូលទៅ Cloudflare Dashboard -> ជ្រើសរើស Domain របស់លោកអ្នក
  2. ចូលទៅ DNS -> Records -> ចុច Add record
  3. បំពេញ៖
    • Type: A
    • Name: stream (នោះ Domain នឹងទៅជា stream.yourdomain.com)
    • IPv4 address: ដាក់លេខ IP របស់ VPS ដែលទើបទិញបាន (ឧ. 157.245.201.238)
    • Proxy status: ចុចបិទឱ្យចេញ ពពកពណ៌ប្រផេះ (DNS only)
  4. ចុច Save

4 ដំឡើងលើ VPS ដោយស្វ័យប្រវត្តិ (1-Click Install)

ចូលទៅកាន់ Terminal របស់ VPS (អាចចុចប៊ូតុង Console លើ DigitalOcean ដោយផ្ទាល់) រួច Copy command ខាងក្រោមនេះទៅ Paste រួចចុច Enter៖

curl -sSL -O https://raw.githubusercontent.com/sensoky25/tg-stream-player/main/setup_vps.sh && bash setup_vps.sh
ប្រព័ន្ធនឹងសួរសំណួរដោយស្វ័យប្រវត្តិ៖
1. Domain: វាយបញ្ចូល stream.yourdomain.com
2. BOT_TOKEN: វាយបញ្ចូល Token ដែលបានពី @BotFather
3. API_ID: វាយបញ្ចូល API ID ពី my.telegram.org
4. API_HASH: វាយបញ្ចូល API Hash ពី my.telegram.org
5. Bin Channel ID: វាយបញ្ចូលលេខ Channel (ឧ. -1003909046470)
6. Email: វាយបញ្ចូល Email សម្រាប់ចុះឈ្មោះ Let's Encrypt SSL
7. Owner ID: វាយបញ្ចូល Telegram User ID ដែលបានពី @userinfobot សម្រាប់ចាក់សោសុវត្ថិភាព
រួចរាល់ ១០០%! ប្រព័ន្ធនឹងដំឡើង Nginx, Python, Let's Encrypt SSL (HTTPS 🔒), បង្កើត Swap Memory 2GB និងបើកឱ្យ Bot ដំណើរការ ២៤/៧ ដោយស្វ័យប្រវត្តិតែម្ដង!
